# Phase 0 Repository Research

Status: mandatory Phase 0 research complete; M2 local-analysis dependency selection implemented
Inspection dates: 2026-08-09 and M2 update 2026-08-11

## Method

Use official documentation first, then inspect each source repository at an exact commit or release. Treat README compatibility, quality, and performance claims as hypotheses until a source inspection or local spike confirms them. Record code licenses separately from model-weight/data licenses. A missing or ambiguous license blocks default distribution until resolved.

## M2 local-analysis selection update

M2 selected external FFmpeg/ffprobe 8.1.2 plus pinned `numpy==2.4.4` for the transparent development provider `ffmpeg-numpy-basic` / `baseline-v1`. Official FFmpeg release, ffprobe/format, and legal pages plus NumPy 2.4.4 package/release/license metadata are linked in `evidence/m2-dependency-selection.md`. Generated fixtures establish deterministic local decode and heuristic feature plumbing only; they do not establish real-music accuracy or broad codec coverage.

The installed Homebrew FFmpeg configuration enables GPL components. M2 invokes it only as Joe's external personal-development prerequisite and does not copy or bundle it. M7 must select/build and verify a reproducible distributable arm64 decoder, exact source/configuration/transitive inventory, notices, signing, codec behavior, and clean setup. No model, weights, downloaded dataset, or executable deserialization was selected.

### Electron and macOS decision synthesis

Current official evidence narrows ADR-0001/0007 without pretending that a
package exists. [Electron 43.2.0](https://releases.electronjs.org/release/v43.2.0)
is a stable release with Node 24.18.0, and the official
[support schedule](https://releases.electronjs.org/schedule) gives its current
support window; Phase 1 must recheck and pin a supported patch. Electron's
[security checklist](https://www.electronjs.org/docs/latest/tutorial/security)
supports the selected mandatory renderer isolation/CSP/navigation/sender controls. Its
[utility-process API](https://www.electronjs.org/docs/latest/api/utility-process)
is Node-specific and lacks general stdin, so it does not replace the explicit
Python supervision/private-socket topology. [ASAR limitations](https://www.electronjs.org/docs/latest/tutorial/asar-archives)
require spawned Python/Codex/native resources and their working directories to
resolve to real non-ASAR paths. Electron recommends
[Forge](https://www.electronjs.org/docs/latest/tutorial/application-distribution/)
for packaging, but exact Forge/maker versions remain a Phase 1 lock decision.

ADR-0001 selects bundled CPython 3.12 as the core runtime major line. The
official [Python version status](https://devguide.python.org/versions/) keeps
3.12 under security support through October 2028, while the inspected
`pyrekordbox` release is explicitly classified through 3.12 and most optional
MIR candidates do not establish Python 3.14 compatibility. Python 3.12 is now
source-only upstream, so Phase 1 must lock a current security patch and prove a
reproducible bundled arm64 build rather than depend on a system interpreter.
This runtime choice does not approve `pyrekordbox` or any MIR provider.

Apple's [Developer ID guidance](https://developer.apple.com/support/developer-id/),
[notarization requirements](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution),
and [hardened-runtime guidance](https://developer.apple.com/documentation/Security/hardened-runtime)
support direct arm64 distribution only after every executable is signed with
least justified entitlements, timestamped, notarized, stapled, and verified.
Apple also documents [sandboxed file selections and security-scoped bookmarks](https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox),
including cross-process transfer, but the Electron→Python→Codex/auth path has no
executable bookmark/sandbox proof. The accepted first-release boundary therefore uses
Chromium renderer sandboxing plus explicit user-selected approved roots without
claiming macOS App Sandbox confinement. Full rationale, the named `Mac17,2`
reference host, architecture budgets, and split unsigned-versus-credentialed
Phase 9 gates are recorded in `docs/evidence/phase-0/framework-packaging.md`.
