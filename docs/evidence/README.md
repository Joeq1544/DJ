# Verification Evidence

Store durable, redacted phase reports under `phase-<n>/`. Each report records date, environment, exact command, inputs/fixture provenance, expected and actual result, exit status, limitations, and the task/acceptance criterion it supports.

Do not store credentials, raw audio, copyrighted fixtures, unrestricted local paths, or massive logs here.

## Historical Phase 0 evidence

Reports under `phase-0/` preserve the exact 2026-08-09 research and feasibility outcomes. Their deterministic gate passed while the original commercial-style product gate remained blocked. The approved 2026-08-10 personal-use scope accepts those recorded limitations and supersedes the stop rule; it does not reinterpret missing MCP, sentinel, ambient-isolation, or containment evidence as passed.

Current execution status lives in `TASKS.md`. New milestone evidence should remain concise and tied to a user-visible flow or a meaningful shared contract.
