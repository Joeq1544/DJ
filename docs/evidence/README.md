# Verification Evidence

Store durable, redacted phase reports under `phase-<n>/`. Each report records date, environment, exact command, inputs/fixture provenance, expected and actual result, exit status, limitations, and the task/acceptance criterion it supports.

Do not store credentials, raw audio, copyrighted fixtures, unrestricted local paths, or massive logs here.
